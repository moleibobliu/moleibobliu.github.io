# Group member photos

Put group member photos in this folder.

Recommended:
- JPG / PNG / WebP
- landscape or near 4:3 ratio
- around 800–1200 px wide
- small file size (ideally under 500 KB)

Then update the corresponding `photo` field in `data.js`, e.g.

```js
photo: "assets/images/people/alice.jpg"
```
